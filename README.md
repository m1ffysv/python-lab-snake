# Консольная игра «Змейка»

Консольная игра «Змейка» с настраиваемыми параметрами поля, скоростью и интерактивным управлением. Лабораторная работа, трек DevOps, вариант Б2.

## Возможности
- **Игровая логика и интерфейс разделены**: классы `Snake` и `Game` вынесены в отдельный модуль (`game/models.py`) и полностью покрыты юнит-тестами.
- **Гибкая настройка**: запуск с аргументами командной строки (`--width`, `--height`, `--speed`) или через интерактивное стартовое меню.
- **Интерактивные меню**: стартовое меню выбора скорости и экран завершения игры (`Game Over`) с возможностью рестарта или выхода.
- **Кроссплатформенное управление**: отзывчивое управление с клавиатуры (`W`, `A`, `S`, `D`), пауза (`P`) и быстрый выход (`Q`).
- **Визуальная компенсация пропорций**: удвоение символов по горизонтали для выравнивания прямоугольной сетки терминала в квадрат.

## Установка

Через менеджер зависимостей и виртуальное окружение **uv** или стандартный **pip**:

```bash
# Создание окружения и установка зависимостей через uv
uv run python snake.py

# Либо стандартный способ через pip
python -m venv .venv
source .venv/bin/activate  # или .venv\Scripts\activate для Windows
pip install -e ".[dev]"
