# Консольная игра «Змейка»

Консольная игра «Змейка» с настраиваемыми параметрами поля, скоростью и интерактивным управлением.

> Лабораторная работа, трек DevOps, вариант Б2.

## Возможности

- **Игровая логика и интерфейс разделены**: классы `Snake` и `Game` вынесены в отдельный модуль (`game/models.py`) и полностью покрыты юнит-тестами.
- **Гибкая настройка**: запуск с аргументами командной строки (`--width`, `--height`, `--speed`) или через интерактивное стартовое меню.
- **Интерактивные меню**: стартовое меню выбора скорости и экран завершения игры (`Game Over`) с возможностью рестарта или выхода.
- **Кроссплатформенное управление**: отзывчивое управление с клавиатуры (`W`, `A`, `S`, `D`), пауза (`P`) и быстрый выход (`Q`).
- **Визуальная компенсация пропорций**: удвоение символов по горизонтали для выравнивания прямоугольной сетки терминала в квадрат.

## Установка

Через менеджер зависимостей и виртуальное окружение **uv** или стандартный **pip**:

```bash
# Создание окружения и установка зависимостей через uv
uv run python snake.py

# Либо стандартный способ через pip
python -m venv .venv
source .venv/bin/activate  # или .venv\Scripts\activate для Windows
pip install -e ".[dev]"
```

## Запуск

| Команда | Что делает |
|---|---|
| `python snake.py` | Запуск игры (при отсутствии параметров открывает интерактивное меню) |
| `python snake.py --width 40 --height 20 --speed 10` | Запуск с конкретными параметрами ширины, высоты и скорости (fps) |
| `uv run python snake.py` | Запуск через менеджер uv |

## Управление в игре

- `W`, `A`, `S`, `D` — движение змейки вверх, влево, вниз, вправо;
- `P` — поставить игру на паузу / снять с паузы;
- `Q` — экстренный выход из игры.

После окончания игры появляется интерактивное меню: можно сыграть ещё раз на той же скорости, вернуться в главное меню или выйти.

## Тесты и проверки кода

Проект полностью соответствует стандартам чистого кода. Локальные проверки:

```bash
pytest -v               # Запуск юнит-тестов
ruff check .            # Проверка линтером Ruff
ruff format --check .   # Проверка форматирования
mypy --strict .         # Строгая типизация
```

Всё это автоматически запускается в GitHub Actions на каждый push (`.github/workflows/ci.yml`). Тесты проверяют игровую логику, движение змейки, рост, столкновения со стенами и с собой.

## Требования и стандарты кода

- **Строгая типизация**: используются аннотации типов во всех модулях, проверка через `mypy --strict`.
- **Линтинг и форматирование**: код проверен линтером `ruff` на соответствие стандартам PEP 8.
- **Автоматизация (CI/CD)**: настроен GitHub Actions для прогона тестов и линтеров.
- **Модульность**: бизнес-логика отделена от интерфейса ввода/вывода, что позволяет тестировать игру без запуска терминала.
